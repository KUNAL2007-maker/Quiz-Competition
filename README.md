# Null Origin — Quiz Competition Platform

A high-performance cybersecurity quiz competition and tournament management platform built with React, Vite, Express, and Firebase Firestore, ready for zero-latency deployment on Vercel.

## Features
- **Deterministic Live Scoring Engine:** Evaluates question submissions, accuracy ratios, time elapsed, and category breakdowns.
- **Real-Time Leaderboard:** Dynamic tournament rankings with instantaneous score updates.
- **Operational Tournament Controls:** Timed upcoming competitions, per-question timers, 3-2-1 countdown sequence, and single-attempt enforcement.
- **Competitor Verification Dossier:** 100% profile completion requirements and admin prize notifications.
- **Zero-Latency Global CDN:** Configured for instant deployment on Vercel Edge Network.

## Local Development
```bash
# Install dependencies
npm install

# Start local development gateway (launches Vite frontend + Python engine)
npm run dev

# Run unit tests
npm test

# Build production assets
npm run build
```
